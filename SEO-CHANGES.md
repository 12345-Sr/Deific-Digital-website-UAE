# SEO + WebP changes (Deific Digital)

## Images -> WebP
- 11 PNGs in src/assets converted to WebP (12.3 MB -> 0.68 MB), imports updated, old PNGs deleted.
- External Unsplash images now request `fm=webp`; picsum URL uses `.webp`.
- og-image.jpg intentionally kept as JPG: WhatsApp / LinkedIn / Facebook link previews do not reliably show WebP.
- Alt text, lazy-loading, decoding=async and width/height added on content images.

## India city SEO
- New: src/static/cities.ts (33 cities), src/pages/CityPage.tsx, src/pages/IndiaHubPage.tsx
- URLs: /software-company-in-<city> (e.g. /software-company-in-kanpur) and hub /software-company-in-india
- Each page: unique title + meta description, canonical, OG/Twitter, Service + FAQPage + BreadcrumbList JSON-LD,
  city-specific industries and localities, nearby-city internal links.
- Footer now links to 13 top cities + the hub on every page.
- To add a city: add an object in cities.ts, then `npm run build` (sitemap regenerates automatically).

## Technical SEO fixes
- New reusable <Seo /> component (src/components/site/Seo.tsx).
- These pages had NO title/canonical, so the prerender copied the HOME canonical into them. Fixed:
  /usa, /team, /technologies, /industries, /terms-and-condition, /privacy-policy, /propai, both blog posts.
- Blog posts now have BlogPosting schema. PropAI title is now prerendered (was client-side only).
- sitemap.xml is generated by scripts/generate-sitemap.mjs on every build (71 URLs; adds /team, /technologies, /industries, hub, 33 cities).
- index.html: lang="en-IN", geo meta, robots meta.

## Known, not changed
- src/pages/TeamPage.tsx line ~134 reads `m.dept` which does not exist (pre-existing type error, build still passes).
- Pre-existing TS errors in calendar.tsx and AiAgent.tsx (not related).

## Round 2: "top software company" targeting
- Kanpur + Delhi pages: title/H1 "Top Software Company in <city>", "how to choose" checklist, real client proof (Kanpur).
- Hub /software-company-in-india retitled for "software companies in India".
- Blog /blog/top-10-it-companies-in-india: new title, quick-answer box, big-IT vs specialist section, city links, FAQ schema.
